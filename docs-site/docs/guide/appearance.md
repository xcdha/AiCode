# 外观与语言

「设置」首页点「外观主题」「背景图」或「语言」会弹出底部选择窗口，选择后立即生效并保存。

## 外观主题

面板里分三块：明暗模式、配色方案、莫奈取色。选择后不会自动关窗，便于连续对比多套配色。

### 明暗模式

三选一：跟随系统、固定深色、固定浅色。

### 配色方案

四套预设，深浅两种模式各自配好：

- **默认蓝**：App 默认的蓝色调。
- **咖啡**：暖赤陶色 + 米白纸感底。
- **石墨**：中性冷灰，颜色干扰最小。
- **森林**：低饱和绿。

色块外圈是该主题的页面底色、内圈是主色，预览会跟随当前明暗模式变化。

Git 泳道色、日志级别色、diff 增删的红绿属于功能标识，不随主题变化，避免同一含义在不同主题下颜色不一致。代码编辑器的语法高亮与终端配色也是各自独立的设置。

### 莫奈取色

开启后从系统壁纸提取配色，上方所选的配色方案不再生效（色块变灰）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，效果不满意关闭即可。

## 外观与主题页

「设置 → 外观主题」现在是一整页，按三组排列：

### 颜色与主题

- **主题模式**：跟随系统 / 深色 / 浅色。
- **配色方案**：默认蓝、咖啡、石墨、森林四套内置配色。
- **Monet 取色**：从系统壁纸提取配色（Android 12+）。开启后配色方案变灰、不再生效。
- **色彩风格**：柔和 / 中性 / 鲜艳 / 表现力 / 彩虹 / 缤纷 / 单色 / 还原 / 内容，决定整套配色的饱和度与色相走向。
- **强色调**：强调色，可选跟随主题、蓝、紫、粉、红、橙、黄、绿、青；选中后覆盖主色，按钮、选中态、进度条等随之改变。

### 界面样式

- **标准 / Miuix**：Miuix 使用更大的圆角与更卡片化的层次，色板不变。
- **界面缩放**：85%~115%，调整全局字号大小。

### 界面与效果

- **纯黑背景**：深色模式下把页面底色压到纯黑，对比更高、更省电。

> 所有选项立即生效并持久化，不需要重启 App。

## 自定义背景

可以设置一张全局背景，支持静态图片、GIF 动图和 MP4 视频三种类型：

- **选择图片 / 视频**：从系统相册选一张图片、一个 GIF 或一段 MP4 视频作为 App 全局背景，叠在所有页面内容上（水印效果，不拦截触摸）。终端页保持纯黑底，不显示背景。
- **透明度**：滑块显示 0% 到 100%，实际生效范围映射到 0% 到 20%（即滑到 100% 相当于 20% 不透明度），以保证文字始终可读。默认 15%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

GIF 与视频会自动**静音循环播放**，不需要手动点击；进后台或离开页面后自动停止，不会在后台持续解码耗电。设置首页的「背景图」一行会显示当前类型（如 `MP4 视频 · 15%`）。

背景文件保存在应用私有目录，**不随备份导出**，更换设备需要重新设置。

> 动态背景比静态图更耗电：视频持续硬解、GIF 每帧重绘。手机发热明显或续航吃紧时，换回静态图即可。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。
